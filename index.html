Safari 아래(아이패드는 위)의 공유 버튼(네모에 위쪽 화살표) → 홈 화면에 추가를 누르세요. 인터넷이 없는 현장에서도 열립니다.
사용 방법
  1. 장비 정보를 입력하고, 작업하면서 항목마다 완료 / 미실시 / 해당 없음을 누릅니다. 측정값은 기준 안인지 자동으로 표시됩니다.
  2. 입력 내용은 이 기기에 자동 저장됩니다. 앱을 닫았다 열어도 이어서 작성할 수 있습니다.
  3. 끝나면 보고서 PDF로 고객용 보고서를 만들어 인쇄하거나 저장합니다.
  4. Sysmex에 보내기를 누르면 보고서 PDF가 첨부된 채로 메일 앱(Outlook 등)이 열립니다. 받는 사람만 붙여 넣고 보내면 됩니다.
